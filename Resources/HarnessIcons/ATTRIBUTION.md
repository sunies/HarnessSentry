# Harness icon sources

These icons identify third-party products; their names and marks remain with
their respective owners. They are not covered by HarnessSentry's Apache-2.0
license, and inclusion does not imply endorsement. Redistributors should check
each owner's current trademark and asset terms.

The following images were supplied by the project user and converted to small,
offline PNGs without changing their shapes: Claude Code, Cursor, GitHub Copilot,
Gemini CLI, DeepSeek Harness, TRAE, and ZCode. Their original download sources
were not provided. The separate `chatgpt.svg` was deliberately not used as a
Codex icon because ChatGPT and Codex are different product identities.

The following icons were obtained from product-owned source repositories:

- Roo Code: https://github.com/RooCodeInc/Roo-Code/blob/main/src/assets/icons/icon.svg
- Continue: https://github.com/continuedev/continue/blob/main/extensions/vscode/media/icon.png
- Aider: https://github.com/Aider-AI/aider/blob/main/aider/website/assets/icons/apple-touch-icon.png
- Goose: https://github.com/block/goose/blob/main/ui/desktop/src/images/icon.svg

The following marks were derived from Simple Icons 16.31.0 and rasterized for
offline display: Cline, Windsurf, OpenCode, Qwen and Kimi.
https://github.com/simple-icons/simple-icons/tree/16.31.0/icons
Simple Icons' project license is CC0 1.0, but individual brand rights may
differ; see https://github.com/simple-icons/simple-icons/blob/16.31.0/DISCLAIMER.md.

For Codex and Qoder, HarnessSentry uses their icons only from applications
already installed on the user's Mac. No copied Codex or Qoder artwork ships in
this repository. If a trustworthy icon is unavailable, a neutral terminal
symbol is shown rather than an invented logo.
